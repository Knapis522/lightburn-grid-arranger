# Version, unterstützte Dateien und Daten

- Version der Anwendung: **Hilfe → Über**.
- Überprüft mit: LightBurn 2.2.00, `.lbrn2`-Projekten, Lasern mit dem Nullpunkt in jeder Ecke (oben links und oben rechts an echten Lasern, unten links und unten rechts mit LightBurn-Testgeräten).
- Die Anwendung arbeitet **offline** und steuert den Laser nicht. Die einzige Internetverbindung ist die Update-Suche auf GitHub (keine Daten über Ihre Projekte); sie lässt sich unter **Einstellungen → Updates** abschalten.
- **Einstellungen** (Eintrag in der Menüleiste, Zahnradsymbol, Strg+,) öffnet ein eigenes Fenster mit den Seiten *Allgemein*, *Laser* (Laserkatalog — siehe [Projekt für einen anderen Laser](prepare.md)), *Speichern* (nicht angehakte Objekte, Speicherprotokoll) und *Updates*. Änderungen werden mit **OK** oder **Übernehmen** wirksam; **Abbrechen** schließt das Fenster ohne Änderungen (nach *Übernehmen* heißt die Schaltfläche **Schließen**).
- **Sprache:** **Einstellungen → Allgemein → Sprache** — Automatisch (nach Windows), Čeština, English, Deutsch, Slovenčina, Polski, Français, Español, Italiano. Jede Sprache wird mit ihrem eigenen Namen angezeigt.
- **Layoutbereich:** **Einstellungen → Allgemein → Layoutbereich** — die Bereiche Projekt, Objekte, Raster, Platzierung und Platte links oder rechts von der Vorschau.
- Darstellung: **Einstellungen → Allgemein → Darstellung** (automatisch nach Windows; hell = ganze Anwendung hell; dunkel = dunkle Bedienelemente, die Plattenvorschau bleibt hell).
- **Einheiten:** **Einstellungen → Allgemein → Einheiten** — Millimeter oder Zoll (wie in LightBurn). Nur Anzeige und Eingabe der Werte ändern sich; Berechnung und gespeichertes Projekt sind immer in Millimetern, daher verschiebt ein Wechsel der Einheiten nichts.
- Die Bereiche des Seitenbereichs (Projekt, Objekte, Raster, …) lassen sich durch Klicken auf ihren Kopf einklappen; der Zustand wird gespeichert.
- Einstellungen (Sprache, Darstellung, Einheiten, Seite des Bereichs, Standardplatten je Laser, Laserkatalog, Profile) werden im Windows-Benutzerprofil gespeichert, nicht im Projekt.
- Installation: `GridArranger-Setup-….exe` ausführen (keine Administratorrechte nötig; die Anwendung erscheint im Startmenü). Ersatz ohne Installation: ZIP entpacken und `GridArranger.exe` starten — sie muss neben dem Ordner `_internal` bleiben.
- **Updates:** Bei aktivierter automatischer Suche (**Einstellungen → Updates**) bietet die Anwendung nach jedem Start eine neue Version an; jederzeit auch über die Schaltfläche **Nach Updates suchen** in **Einstellungen → Updates** (oder Hilfe → Nach Updates suchen). Es wird immer die neueste Version mit den Änderungen seit Ihrer Version angeboten. Sie können sie installieren (die Anwendung schließt sich, installiert die neue Version und startet erneut), später erinnern lassen oder die Version überspringen — eine neuere wird wieder angeboten. Ohne Ihre Zustimmung wird nichts installiert; das heruntergeladene Installationsprogramm wird vor dem Start mit einer Prüfsumme verifiziert. Vorabversionen (Testversionen) werden nur angeboten, wenn „Auch Vorabversionen anbieten“ aktiviert ist.
- Ein Projekt lässt sich auch öffnen, indem man eine `.lbrn2`-Datei auf `GridArranger.exe` zieht.
- Eine Kopie aus dem ZIP wird manuell aktualisiert: neue Version in einen neuen Ordner entpacken; die Einstellungen bleiben erhalten.
