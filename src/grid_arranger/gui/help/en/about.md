# Version, supported files and data

- Application version: **Help → About**.
- Verified with: LightBurn 2.2.00, `.lbrn2` projects, lasers with the origin at the top left and top right.
- The application works **offline**, sends nothing and does not control the laser.
- Appearance: **Settings → Appearance** (automatic from Windows; light = the whole application light; dark = dark controls, the board preview stays light).
- Settings (language, appearance, default boards per laser) are stored in the Windows user profile, not in the project.
- No installation needed: unpack the ZIP and run `GridArranger.exe`. The `GridArranger` folder can be moved anywhere; `GridArranger.exe` must stay next to the `_internal` folder.
- A project can also be opened by dropping a `.lbrn2` file onto `GridArranger.exe`.
- Updating: unpack the new version into a new folder; settings are kept.
