# Introducción

**Grid Arranger for LightBurn** mueve grupos (elementos) existentes y distintos entre sí de un proyecto de LightBurn `.lbrn2` a una cuadrícula exacta y guarda un proyecto **nuevo**. El contenido de los grupos no se modifica — solo su posición (y su rotación, si lo desea); las copias solo se añaden cuando usted lo pide. El archivo original nunca se sobrescribe.

> Herramienta no oficial, no es un producto de LightBurn Software. Compruebe siempre el resultado en LightBurn mediante **File → Open** y **Preview** antes de cortar.

**Controles:** la barra de herramientas de arriba — **Abrir proyecto** (Ctrl+O), **Guardar como proyecto nuevo** (Ctrl+S), **Abrir en LightBurn** (Ctrl+L), **Deshacer** (Ctrl+Z) y **Rehacer** (Ctrl+Y), **Crear copias** (Ctrl+D), **Llenar la plancha con copias** (Ctrl+Mayús+D), **Ajustar la vista** (Ctrl+0), **Configuración** (Ctrl+,), **Guía de usuario** (F1); pase el ratón sobre un icono para ver su descripción. **Reordenar la barra de herramientas** arrastrando: tome un icono, manténgalo y arrástrelo a otro lugar (una línea verde indica dónde); el orden se recuerda. Con el botón derecho sobre la barra se restaura la disposición predeterminada. Deshacer/Rehacer se aplica a la distribución en la aplicación (orden, copias, rotación, cuadrícula, plancha), no al proyecto en LightBurn. La barra de título muestra el nombre del proyecto abierto.
