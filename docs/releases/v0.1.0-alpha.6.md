# Grid Arranger for LightBurn v0.1.0-alpha.6

**Release date:** not released yet
**Type:** pre-release — not for unsupervised production use

## What's new

- **Number of pieces per item:** set *Pieces* for the selected items — the original plus copies placed right after it, so the items stay grouped by variant. Lower it to remove the newest copies, or set 0 to leave the item out. CLI: `--quantity ID=N`.
- **Leave objects out of the output:** objects you do not tick are no longer written to the saved project, and the grid ignores them — handy when you only need part of a large project. Press **Delete** to leave out selected objects (grey groups too); they stay crossed out at the bottom of the list, and *Edit → Restore left-out objects* brings them back. The original project is never changed. To keep unticked objects in place as before (the grid avoids them), choose *Settings → Saving → Objects that are not ticked → Keep in place*.
- **Six more languages:** the interface and the offline user guide are now available in German, Slovak, Polish, French, Spanish and Italian, in addition to Czech and English. Choose one in *Settings → General → Language*, or leave it on *Automatic* to follow Windows. These translations were machine-made (AI) and have not yet been reviewed by native speakers — corrections are welcome, see `docs/TRANSLATING.md`.

## Compatibility

- Windows 10/11 x64, no Python needed. LightBurn 2.2.x projects (`.lbrn2`); verified with LightBurn 2.2.00-RC-7. Lasers with the origin in any corner.

## Install / update

The application offers this version itself (*Settings → Updates → Check for updates*, with *Include pre-release versions* switched on). Alternatively run `GridArranger-Setup-v0.1.0-alpha.6-win-x64.exe` — it installs over the previous version and keeps your settings. Optionally verify it against `SHA256SUMS.txt` (PowerShell: `Get-FileHash <file>`).

## Safety

Always open the output in LightBurn with **File → Open** (not Import) and check the position, layers and **Preview** before cutting.
