# Grid Arranger for LightBurn v0.1.0-alpha.5

**Release date:** not released yet
**Type:** pre-release — not for unsupervised production use

## What's new

- **Prepare a project for another laser.** Choose *Prepare for:* in the Project section to save the output for another laser from the new **laser catalogue** (*Settings → Lasers*): its board is offered, the grid is filled from its origin, and the items are mirrored so that they look the same on that laser — no more switching the device and flipping the design in LightBurn. Layer settings (power, speed) are kept from the original project; check them in LightBurn. *(Before release: fill in the result of the KAL-05 check.)*
- **Lasers with the origin at the bottom** (bottom left / bottom right, typical for diode lasers): such projects are now opened instead of refused. The grid is filled from the corner at the laser origin (first row at the bottom), placed into the board corner at the origin, and manual position and rotation work as for the top origins. *(Before release: fill in the result of the KAL-04 check in LightBurn.)*

## Changed

- **Update check on every start:** with *Check for updates automatically* switched on (*Settings → Updates*), the application now checks for a new version each time it starts (previously at most once a day).

## Compatibility

- Windows 10/11 x64, no Python needed. LightBurn 2.2.x projects (`.lbrn2`); verified with LightBurn 2.2.00-RC-7. Lasers with the origin in any corner.

## Install / update

The application offers this version itself (*Settings → Updates → Check for updates*, with *Include pre-release versions* switched on). Alternatively run `GridArranger-Setup-v0.1.0-alpha.5-win-x64.exe` — it installs over the previous version and keeps your settings. Optionally verify it against `SHA256SUMS.txt` (PowerShell: `Get-FileHash <file>`).

## Safety

Always open the output in LightBurn with **File → Open** (not Import) and check the position, layers and **Preview** before cutting.
