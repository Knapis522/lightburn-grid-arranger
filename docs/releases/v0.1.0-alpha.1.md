# Grid Arranger for LightBurn v0.1.0-alpha.1

**Release date:** 2026-10-16
**Type:** internal pre-release (private repository) — not for unsupervised production use

First packaged build of Grid Arranger: a Windows desktop tool that moves existing, distinct groups of a LightBurn `.lbrn2` project into an exact grid and saves the result as a **new** project. The original file is never modified.

## What's new

- Open a `.lbrn2` project; the laser (`DeviceName`) and its origin corner are detected from the file.
- Item list: select items, reorder them (Up/Down, default order) or swap two items by dragging them in the preview.
- Adaptive grid: number of columns, X/Y gap in mm; column width and row height follow the largest item.
- Placement relative to the laser origin (default), the board centre, a manual corner or the original position; filling starts at the laser origin.
- Board size prefilled per laser (5 mm margin by default), can be saved as the default for that laser.
- Live preview with the real artwork in layer colours; errors and warnings below it.
- Save is enabled only when the layout is valid (inside the board, no collisions, gaps respected, unmovable objects avoided); the output `…__grid_NNN.lbrn2` is independently re-verified (every byte outside the moved positions must be unchanged), and a JSON protocol is written next to it.
- Czech and English UI with switching at run time; offline user guide (F1) in both languages.
- Light / dark / automatic appearance.
- Portable build: no Python or installation required; `GridArranger.exe --self-test report.json` checks the installation.

## Compatibility

- Windows 10/11 x64.
- LightBurn 2.2.x projects (`.lbrn2`, FormatVersion 1); verified with LightBurn 2.2.00-RC-7.
- Lasers with the origin at the top left or top right (`MirrorY=True`).

## Known limitations

- Rejected projects: `.lbrn` (old format), other LightBurn versions, origin at the bottom, multi-page projects, unknown XML constructs.
- Items that cannot be moved (shown greyed out with the reason): groups without exactly one closed outline containing all their content, locked groups, groups containing other object types than paths, groups and text (e.g. bitmaps).
- The project thumbnail is not regenerated; LightBurn updates it on the next save.
- The application is not digitally signed; Windows SmartScreen may show a warning ("More info" → "Run anyway").
- Not yet verified on a PC without Python (GH-05) or in regular production (MVP-ACCEPT).

## Install / update

1. Download `GridArranger-v0.1.0-alpha.1-win-x64.zip` and verify it against `SHA256SUMS.txt` (PowerShell: `Get-FileHash .\GridArranger-v0.1.0-alpha.1-win-x64.zip`).
2. Unpack it to a new folder and run `GridArranger\GridArranger.exe`; keep `GridArranger.exe` next to `_internal`.
3. Settings (language, appearance, boards per laser) are stored in the Windows user profile and survive updates.

## Safety

Always open the output in LightBurn with **File → Open** (not Import) and check the position, layers and **Preview** before cutting. The checks in this application do not replace the machine operator's check.
