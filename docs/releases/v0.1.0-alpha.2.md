# Grid Arranger for LightBurn v0.1.0-alpha.2

**Release date:** not released yet
**Type:** internal pre-release — not for unsupervised production use

## What's new

- **Installer** `GridArranger-Setup-v0.1.0-alpha.2-win-x64.exe`: installs for the current user without administrator rights, adds a Start menu entry (optional desktop icon) and an uninstaller. New versions install over the old one and keep your settings. The portable ZIP is still available as a fallback.
- **Updates:** *Settings → Updates* (check automatically, include pre-release versions) and *Help → Check for updates*. The newest release is always offered together with the changes since your version; choose *Download and install*, *Remind me later* or *Skip this version*. Nothing is downloaded or installed without your consent, and the installer is verified against `SHA256SUMS.txt` before it runs. The application restarts itself after the update.
- Czech buttons in standard dialogs (Yes/No, Cancel).

## Compatibility

- Windows 10/11 x64. LightBurn 2.2.x projects (`.lbrn2`); verified with LightBurn 2.2.00-RC-7. Lasers with the origin at the top left or top right.

## Known limitations

- Update checks need a public repository: while the repository is private, *Check for updates* reports that no public releases were found.
- v0.1.0-alpha.1 has no updater — install this version manually once; later versions can be installed from the application.
- Same project limitations as in v0.1.0-alpha.1 (`.lbrn`, bottom origin, multi-page projects and unsupported item contents are rejected).
- The installer is not digitally signed; Windows SmartScreen may show a warning ("More info" → "Run anyway").

## Install / update

1. Download `GridArranger-Setup-v0.1.0-alpha.2-win-x64.exe` (or the ZIP) and optionally verify it against `SHA256SUMS.txt` (PowerShell: `Get-FileHash <file>`).
2. Run the installer. Settings from the ZIP version (language, appearance, boards per laser) are reused automatically.

## Safety

Always open the output in LightBurn with **File → Open** (not Import) and check the position, layers and **Preview** before cutting.
