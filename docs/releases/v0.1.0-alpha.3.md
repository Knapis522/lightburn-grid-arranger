# Grid Arranger for LightBurn v0.1.0-alpha.3

**Release date:** not released yet
**Type:** internal pre-release — not for unsupervised production use

## What's new

- **Rotation to save material.** New *Rotation* option in the Grid section: *Any angle (smallest area)* (default), *In 90° steps* or *Do not rotate*. Each item is turned so that the rectangle around its real curves is as small as possible, and the whole grid is tried in landscape and portrait; rotation is only used when the grid really gets smaller (preferably so that it fits on the board). Single items can be excluded with *No rotation*. Texts and artwork rotate with the item; the output is checked independently before it is saved. Verified in LightBurn for both laser origins.
- **Shapes drawn directly in LightBurn.** Circles and ellipses, rectangles (without rounded corners) and hexagons can now be the item outline or part of the item, including nested groups such as key rings (circle with a hole in its own group + text). Other polygons and rectangles with rounded corners are still refused with a hint to use *Convert to Path* in LightBurn.
- **Toolbar** with icons: *Open project* (Ctrl+O), *Save as new project* (Ctrl+S), *Fit preview* (Ctrl+0) and *User guide* (F1). The icons adapt to the light and dark appearance.
- The **window title** shows the open project next to the application name and version, as in LightBurn.
- **Save dialog:** choose the folder and the name of the new project (the suggested name stays `original__grid_NNN.lbrn2`). Existing files and the original are never overwritten.
- **Save protocol is optional:** *Settings → Save protocol* — *Do not save* (default), *Next to the saved project*, or *Application protocol folder*.
- **Units:** *Settings → Units* — millimetres or inches, like LightBurn (display and input only; the project is always stored in mm).
- **Left panel redesign:** collapsible sections with clearer headers, narrow value fields, pairs of values side by side. The greyed *Corner X/Y* fields always show the computed grid corner.

## Fixed

- Curves with smooth nodes (LightBurn's `S` vertex flag, e.g. edited key rings) are no longer reported as unreadable.

## Compatibility

- Windows 10/11 x64. LightBurn 2.2.x projects (`.lbrn2`); verified with LightBurn 2.2.00-RC-7. Lasers with the origin at the top left or top right.

## Known limitations

- Update checks need a public repository; while it is private, *Check for updates* reports that no public releases were found.
- Polygons other than hexagons and rectangles with rounded corners drawn as LightBurn shapes are not supported yet (convert them to a path in LightBurn).
- Same project limitations as in earlier versions (`.lbrn`, bottom origin, multi-page projects and unsupported item contents are rejected).
- The installer is not digitally signed; Windows SmartScreen may show a warning ("More info" → "Run anyway").

## Install / update

Run `GridArranger-Setup-v0.1.0-alpha.3-win-x64.exe` — it installs over the previous version and keeps your settings. Optionally verify it against `SHA256SUMS.txt` (PowerShell: `Get-FileHash <file>`).

## Safety

Always open the output in LightBurn with **File → Open** (not Import) and check the position, layers and **Preview** before cutting.
