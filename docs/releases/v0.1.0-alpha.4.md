# Grid Arranger for LightBurn v0.1.0-alpha.4

**Release date:** 2026-10-18
**Type:** pre-release — not for unsupervised production use

## What's new

- **Undo / Redo** (Ctrl+Z / Ctrl+Y, toolbar, Edit menu) for the layout: item order and selection, copies, manual rotation, grid, placement and board (up to 200 steps).
- **Rearrange the toolbar** by dragging its icons; the order is remembered (right-click the toolbar to restore the default).
- **Settings window:** *Settings* now opens a dialog with pages (*General*, *Saving*, *Updates*) instead of a growing menu — menu bar, gear icon on the toolbar or Ctrl+,. Changes apply with OK or Apply; Cancel changes nothing.
- **Layout panel on the left or right** of the preview (*Settings → General → Layout panel*); the side and the panel width are remembered.
- **Open in LightBurn:** after saving, open the new project in LightBurn with one click (save message, toolbar icon, *File → Open saved project in LightBurn*, Ctrl+L). It works like a double-click in Explorer: a running LightBurn opens it instead of the current project and asks about unsaved changes itself.
- **Clear status after saving:** the window title and the Project section show *last saved as …* — you keep arranging the original and each save creates another variant. Tick *Continue working on the saved file here* in the save message to switch to the saved file instead (like "Save as"); its next save continues the original's numbering (`_002`).

## Fixed

- The window opens the way it was closed: size, position, maximized state and the width of the layout panel are remembered.
- The list of check results below the preview is only as tall as its messages (up to 6 rows) and is hidden when no project is open, leaving more room for the preview.

## Compatibility

- Windows 10/11 x64, no Python needed. LightBurn 2.2.x projects (`.lbrn2`); verified with LightBurn 2.2.00-RC-7. Lasers with the origin at the top left or top right.
- The `.lbrn2` writing is unchanged since v0.1.0-alpha.3.

## Known limitations

- Same project limitations as in earlier versions (`.lbrn`, bottom origin, multi-page projects and unsupported item contents are rejected).
- *Open in LightBurn* uses the program associated with `.lbrn2` files; LightBurn opens the file in its current window (it cannot open a second project window).
- The installer is not digitally signed; Windows SmartScreen may show a warning ("More info" → "Run anyway").

## Install / update

The application offers this version itself: in v0.1.0-alpha.3 use *Settings → Updates → Check for updates* (with *Include pre-release versions* switched on) or *Help → Check for updates*. Alternatively run `GridArranger-Setup-v0.1.0-alpha.4-win-x64.exe` — it installs over the previous version and keeps your settings. Optionally verify it against `SHA256SUMS.txt` (PowerShell: `Get-FileHash <file>`).

## Safety

Always open the output in LightBurn with **File → Open** (not Import) and check the position, layers and **Preview** before cutting.
