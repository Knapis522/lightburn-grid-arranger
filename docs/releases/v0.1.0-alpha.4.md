# Grid Arranger for LightBurn v0.1.0-alpha.4

**Release date:** not released yet
**Type:** pre-release — not for unsupervised production use

## What's new

- The window opens the way it was closed: size, position, maximized state and the width of the left panel are remembered.

## Compatibility

- Windows 10/11 x64, no Python needed. LightBurn 2.2.x projects (`.lbrn2`); verified with LightBurn 2.2.00-RC-7. Lasers with the origin at the top left or top right.

## Install / update

The application offers this version itself (*Settings → Updates → Check for updates*, with *Include pre-release versions* switched on). Alternatively run `GridArranger-Setup-v0.1.0-alpha.4-win-x64.exe` — it installs over the previous version and keeps your settings. Optionally verify it against `SHA256SUMS.txt` (PowerShell: `Get-FileHash <file>`).

## Safety

Always open the output in LightBurn with **File → Open** (not Import) and check the position, layers and **Preview** before cutting.
